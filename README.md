# 字母 Wordle

一个模仿原版 Wordle 的四位字母猜词游戏：**4 个字母、4 步机会**。
和原版不同的是，每提交一步就会翻开**字母与汉字的对照**。

## 玩法

1. 输入四个字母并提交，它有 4 个字母。
2. 每个字母对应一个汉字，拼起来就是答案的中文名（例如 `hgcn` → `花宫初奈`）。
3. 每提交一步，字母下方都会显示**你这次输入里该字母对应的汉字**（四个全显示），同时颜色告诉你字母猜得怎么样：
   - 绿色：字母与位置都对；
   - 黄色：答案里有这个字母，但不在这个位置；
   - 灰色：答案里没有这个字母。
4. 盘面下方的「字母 ⇄ 汉字对照」把最近一步的四个字母和汉字完整列一遍。
5. 键盘用原版的三行 QWERTY 排布，词库中不存在的字母（如 `i`、`o`、`u`、`v`）会变灰并禁用。
6. 只接受词库中存在的字母组合；四次之内猜中即胜，结束时弹出结算弹窗，可以「看看盘面」或「再来一局」。

颜色说的是**字母**猜得对不对；汉字永远是你自己这次输入的字，不随颜色改变。

## 数据来源

| 来源 | 说明 |
| --- | --- |
| `public/data.json` | 词组列表，共 587 条 `[汉字, 字母]`，字母组合用于校验输入。同一个字母组合可能对应多个名字（576 个唯一组合）。 |
| `.env` 的 `ANSWER_API` | 今日答案接口，返回裸字母组合（如 `hgcn`）。由 `vite.config.ts` 读取后以编译期常量注入前端。 |

`.env` 里的变量默认只有 `VITE_` 前缀才会暴露给客户端，所以 `vite.config.ts` 用 `loadEnv(mode, envDir, '')` 读取原始的 `ANSWER_API`，再通过 `define` 注入为 `__ANSWER_API__`。换接口只需改 `.env` 后重启开发服务器。

## 开发

```bash
pnpm install
pnpm dev      # 开发服务器
pnpm build    # 类型检查 + 产物构建
pnpm preview  # 预览构建产物
```

```

├── game/
│   ├── types.ts       # 牌面、字母状态等类型与常量

│   └── evaluate.ts    # Wordle 判定规则与汉字揭晓逻辑
├── composables/
│   └── useWordle.ts   # 游戏状态机（加载 → 进行中 → 胜/负）

    ├── GameBoard.vue      # 4 × 4 盘面
    ├── GameCell.vue       # 单个字母格（含汉字与翻牌动画）
    ├── MappingPanel.vue   # 字母 ⇄ 汉字对照面板

```

## 判定规则说明

判定完全遵循原版 Wordle：先标记位置正确的字母，剩余字母再按答案中尚未使用的副本数标记为「存在」。因此重复字母只会按答案中的实际出现次数计入。

汉字来自你这一笔提交的字母组合在词库里的名字。同一个字母组合可能对应多个名字（587 条里只有 576 个唯一组合），此时显示的是答案那一支的写法；如果你猜的组合正好是答案，显示就是答案本身。
